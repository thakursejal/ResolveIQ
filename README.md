# 🧠 ResolveIQ

AI-powered Customer Escalation Intelligence using Hindsight Memory.

ResolveIQ helps support teams remember previous customer issues, failed troubleshooting attempts, successful resolutions, and escalation history. When a similar issue appears, it recalls organizational memory and recommends whether to continue troubleshooting or escalate.

## 🔄 How It Works

**Remember → Recall → Decide → Resolve → Learn**

## ✨ Features

- 🧠 Persistent organizational memory using Hindsight
- 🔎 Recalls similar historical customer cases
- 🔁 Detects recurring failures
- 🚨 Recommends escalation when previous troubleshooting has failed
- 💾 Stores successful resolutions for future cases
- 📊 Simple Streamlit interface

## 🛠️ Tech Stack

**Python • Streamlit • Hindsight • Ollama • Gemma 3 12B • Docker**
